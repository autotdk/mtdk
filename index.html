Bắt đầu

Cài đặt trong bốn bước

Không cần cài game hay giả lập từ trước — client Mobile do chính mTDK cài.

Tải file về

Bấm nút vàng ở đầu trang. Chỉ có một file mTDK.exe, không có bộ cài.

Đặt vào thư mục thường rồi mở lên

Ví dụ D:\mTDK hoặc ngay trên Desktop. Đừng để trong Program Files — Windows không cho tool tự cập nhật ở đó.

Kích hoạt key

Nhập key ở tab Key, hoặc mua/gia hạn bằng mã QR ngay trong tool. Có key còn hạn thì mới cài được client.

Cài client, thêm tài khoản, đăng nhập

Sang tab Đăng nhập, bấm Cài client Mobile và chờ tải xong (lần đầu vài GB). Sau đó thêm tài khoản Mobile, tick chọn và bấm đăng nhập. Vào game rồi thì chọn việc và bấm Bắt đầu như bình thường.

Nếu Windows Defender báo file nguy hiểm: tool đọc và ghi bộ nhớ của tiến trình game để điều khiển nhân vật — đúng cái mà phần mềm diệt virus được dạy để chặn. Thêm ngoại lệ cho thư mục chứa mTDK.exe rồi tải lại, hoặc chọn "Giữ lại" (Keep) trong hộp thoại cảnh báo của trình duyệt.
Hỏi đáp

Câu hỏi hay gặp

mTDK khác iTDK thế nào?

iTDK dành cho server PC. mTDK dành cho server Mobile: tự cài client Mobile lên máy tính và đăng nhập bằng tài khoản Mobile. Phần auto (phó bản, thu thập, đồng bộ…) dùng chung một bộ máy nên cập nhật song song.

Hai tool dùng key riêng: key iTDK không kích hoạt được mTDK và ngược lại. Có thể mở cả hai cùng lúc, mỗi tool chỉ điều khiển cửa sổ game của mình.

Có cần cài game hay giả lập Android trước không?

Không. mTDK tự tải client từ máy chủ chính thức của nhà phát hành và kiểm lại từng file. Nếu máy đã có game bản PC, những file giống nhau được lấy lại từ đó nên tải nhanh hơn.

Mạng chập chờn cũng không sao: lần sau bấm lại, tool chỉ tải tiếp phần còn thiếu.

Mật khẩu tài khoản game có bị gửi đi đâu không?

Mật khẩu chỉ được gửi tới máy chủ đăng nhập chính thức của nhà phát hành, giống hệt khi bạn đăng nhập trên điện thoại. Máy chủ trả về mã đăng nhập để vào game; mỗi lần vào game tool xin mã mới, không dùng lại mã cũ.

Key hết hạn thì client có còn không?

Client Mobile đi kèm key. Khi key hết hạn, mTDK tự gỡ client để giải phóng ổ đĩa. Gia hạn xong, bấm Cài client Mobile là tool cài lại.

Cập nhật bản mới thế nào?

Không phải làm gì cả. Mỗi lần mở lên, tool tự hỏi máy chủ xem có bản mới không; có thì hiện hộp thoại, bấm Cập nhật là nó tự tải, tự thay và mở lại.

Riêng những bản đánh dấu bắt buộc thì không có nút "Để sau" — thường là khi game vừa vá và bản cũ đã chạy sai, chạy tiếp lúc đó rất dễ mất tài khoản.

Chạy được bao nhiêu cửa sổ game cùng lúc?

Không giới hạn từ phía tool — mỗi cửa sổ game là một dòng trong danh sách. Giới hạn thật nằm ở RAM và CPU máy bạn, vì mỗi cửa sổ game là một tiến trình riêng.

Đặt trong Program Files có sao không?

Tool vẫn chạy, nhưng đến lúc tự cập nhật thì Windows chặn việc ghi đè và tool sẽ báo lỗi. Đặt ở thư mục thường (Desktop, D:\mTDK…) thì mọi thứ trơn tru.
